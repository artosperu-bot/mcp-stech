# Carpetas de Excel por canal

Usar estas carpetas para entradas y salidas de plantillas.

- `FALABELLA/ENTRADA`: colocar aquí la plantilla Falabella a procesar.
- `FALABELLA/SALIDA`: el sistema deja aquí el Excel completado.
- `COOLBOX/ENTRADA` y `COOLBOX/SALIDA`: reservado para el flujo Coolbox.
- `VTEX/ENTRADA` y `VTEX/SALIDA`: reservado para el flujo VTEX.
- `MERCADOLIBRE/ENTRADA` y `MERCADOLIBRE/SALIDA`: reservado para Mercado Libre.

Los archivos `.xlsx` no se versionan en Git.
